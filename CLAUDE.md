# Reaction Chamber

Monorepo for virtual chemistry sandbox (M0–M5 complete + realistic bench / simplified UI rework).

- `web/`: Frontend UI (TypeScript, Vite, Three.js r170 3D bench, Web Workers)

tier estimated), `solubility.rs` also holds the PubChem lookup queue (`request_lookup`/`take_lookups`/`resolve_mineral`/`apply_solubility`), `acid_estimate.rs` (functional-class pKa ladders, tabulated strong-acid list), `smiles.rs` (minimal SMILES graph reader for functional-group confirmation), `vle.rs` (saturation-pressure models from species records: IAPWS-IF97 region 4 / Wagner / Antoine equations, Lee-Kesler corresponding states anchored on a labelled point, Clausius-Clapeyron fit; Clapeyron latent heat; Henry constants from mu0(aq)-mu0(g); `VleCache`), `eos.rs` (ideal gas + Peng-Robinson), `gas_phase.rs` (`Atmosphere`: pressure, dry composition, relative saturation as vessel inputs), `vessel_vle.rs` (open-vessel bubble-point boiling and evaporation, Henry exchange, sealed isochoric flash with implicit-T latent heat, stopper pop/burst venting, gas dosing), `groups.rs` (exact-cover UNIFAC subgroup assignment from SMILES via the table's own SMARTS), `db/seed_vle.rs` + `data/unifac_vle.json` (critical constants, saturation points, standard air; the full original UNIFAC table of 113 subgroups / 54 main groups / 1270 pairs parsed by `pipeline/db/parse_unifac.py`, plus the unused Magnussen LLE matrix) and `data/excess_volume.json` (Redlich-Kister excess volumes by InChIKey), `conservation.rs` (`ElementLedger`: cumulative per-element ledger)
- `server/`: Local mode server (Python FastAPI, tblite GFN2-xTB, SQLite flywheel); `data_proxy.py` (NIST WebBook table parser, core table matched by InChIKey/CAS, per-user cache in the platformdirs cache dir with TTL, 5 s rate limit, session-token auth; Wikidata off)
- `pipeline/`: Data bundle builder (PHREEQC, IUPAC pKa, Joback additivity over the RDKit graph, curated colors, ~70 hand-checked species; the synthetic homologous series / salt matrix were removed in Stage 0)
- `tests/`: Automated test suite for M0–M2 gates

## Design invariants
- **Intrinsic data in, models for the environment.** The simulation relies as much as possible on *intrinsic* values for each
  compound (properties that do not depend on conditions): standard enthalpy and entropy of formation, heat-capacity
  parametrisation, molar mass, molecular structure, acid dissociation constants at a reference state, standard
  potentials, solvation / activity parameters. Quantities that depend on external factors (melting and boiling point,
  vapour pressure, solubility, density at a temperature, pH, state of matter) are *derived* with equations and models
  (Gibbs energy and K(T), Clausius-Clapeyron / Clapeyron, Raoult / Henry / activity models, Antoine, van't Hoff, ...) from
  the vessel's temperature, pressure, composition and solvent. Never store a condition-dependent value as if it were a
  property of the compound; if a database only offers one (e.g. a normal boiling point), store it as a labelled *point on
  a curve* (e.g. (T, 101325 Pa) for the vapour-pressure fit) and derive everything else from it. Phase is never stamped at
  import. When a derived value must be estimated, label its provenance tier (Tabulated / Imported / Estimated /
  Speculative) and prefer sources in order: measured intrinsic data -> group-additivity / semi-empirical estimates.
- Products are compounds exactly like reagents (same import path, same data), because a product can be the next reactant.
- **Master plan for generalisation: `docs/plans/generalization-master-plan.md`** (audit of how every reaction outcome is determined, model choices, the minimal large-database stack, staged implementation with numeric gates). Evidence and probe scripts: `docs/plans/generalization-audit/`. Older background: `COMPOUND_PHASE_PLAN.md`, `docs/plans/generality-audit.md` (F1–F47), `docs/plans/data-sources.md`.

## Quickstart
``# Launch server and app
python3 run.py

# Run M7 data flywheel (batch precomputations for ML model, e.g. 50 reactions with 4 parallel workers)
python3 run.py --flywheel --flywheel-count 50 --flywheel-workers 4

# Check flywheel stats
python3 run.py --flywheel-stats

# Export ML training dataset
python3 run.py --export-ml ml_dataset.json

# Run tests
pytest tests/ -v

# Run engine tests
cd engine && cargo test

# Build WASM engine
cd engine && wasm-bindgen target/wasm32-unknown-unknown/release/reaction_chamber_engine.wasm --out-dir ../web/src/wasm/engine --target web

# Build bundle
python3 pipeline/build_bundle.py

# Build frontend
cd web && npm run build
```

- **Stage 5 of the generalization master plan (2026-10-02)**: SLE and LLE, partitioning, every compound gets phases (gate numbers and gaps in `docs/plans/generalization-progress.md`).
  - One mechanism: `Vessel::phase_flash` (`vessel_phase.rs`) re-establishes the solid-liquid and liquid-liquid equilibrium at conserved enthalpy every step. Solids follow Schroder-van Laar, `ln a_sat(T) = -dG_fus(T)/RT` from a species record's `tm` + `dhfus` points (ice, naphthalene, I2, hexane... same code), against liquid-reference activities `x*gamma` from UNIFAC (`molecule.rs`); solvent freezing, colligative depression, molecular-solid solubility, melting plateaus and sublimation all fall out. A pure component's equilibrium amount is a step in T, so the root search ends in the lever rule (the plateau). `lle.rs` splits the liquid into up to 3 phases (tangent-plane test + multiphase Rachford-Rice); `species_mol` is the primary (water-containing) phase, `extra_liquids` the others densest first, `remove_liquid_bottom` drains in that order, snapshot layers are sorted by computed density.
  - Activity data: UNIFAC groups from the SMILES (`groups.rs` + `smarts.rs`), plus *activity points* (measured solubility = ln gamma at its saturation mole fraction, or aqueous standard state mu0(aq)-mu0(liquid) = gamma_inf) applied as a two-suffix Margules excess Gibbs energy (Gibbs-Duhem consistent), temperature dependence from `dh_sol` when measured (else regular-solution T_ref/T). Ions: ionic water activity and Long-McDevit salting-out of neutral solutes. Species with neither groups nor points stay in the primary phase (labelled ideal).
  - Every molecule has solid/liquid/gas phases: neat reagents are dosed neat, catalog solutions are recipes (solutes exact, solvent fills 1 mL at 20 C, dosed so the volume is the requested one at the dose temperature), dissolved molecules evaporate and solids sublime (open and sealed; `step_sealed_sublimation`), I2(aq) finds its liquid twin by InChIKey.
