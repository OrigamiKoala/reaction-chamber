# Reaction Chamber

Monorepo for virtual chemistry sandbox (M0–M5 complete + realistic bench / simplified UI rework).

## Structure
- `web/`: Frontend UI (TypeScript, Vite, Three.js r170 3D bench, Web Workers)
  - `src/bench/`: `scene.ts` (BenchScene: renderer, OrbitControls, picking, stations, instruments, placement, animate* API), `glassware.ts` (vessel bundles: profile-driven glass, graduation decals, level line, stopcock/plunger/lid APIs), `lab_room.ts` (worktop, tiled wall, shelf, lights, PMREM env), `shelf.ts` (capped LRU reagent shelf, 27 slots), `animations.ts` (canned pour / drops / spatula / ribbon / move tasks + continuous `PourStream`, `PowderStream`, `MetalPieces`, `DropFall`), `handling.ts` + `handling_math.ts` (manual grab/carry/drop, tilt-to-pour state machine, pipette/syringe modes; all tuning constants), `titration.ts` + `titration_math.ts` (titration station, burette/separatory-funnel stopcock levers, drain targets), `pipetting.ts` + `pipetting_math.ts`, `gas_collection.ts` + `gas_math.ts` (delivery tube, collectors), `filtration.ts` + `filtration_math.ts`
  - `src/render/`: `glass_profiles.ts` (real-size lathe profiles for all 52 `VesselType`s, 1 unit = 1 cm, exact volume↔height tables, downward scales for burettes/pipettes) + `glass_catalog_profiles.ts` (per-type dimensions) + `glass_accessories.ts` (stopcock, side arm, plunger, lid, ring stand, rack), `glass_material.ts` (far/near split glass with fresnel), `liquid_material.ts` (per-pixel Beer–Lambert absorb pass + surface pass, layers, meniscus, ripples, vortex), `liquid_shader.ts` (`computeSpectralColor`), `effects.ts` (bubbles, foam, steam, fumes, condensation, precipitates, flame, shatter), `particles.ts`, `flame.ts`, `textures.ts` (all procedural)
  - `src/equipment/`: thermometer, pH meter, balance, pressure gauge, hot plate/stirrer, burner, `bottle.ts` (data-driven reagent bottles + labels), `lcd.ts`, `stir_plate.ts`, `pipette_bulb.ts`; the balance weighs only what is on its pan (`setLoad`, `tare`, `panWorld`, 3D TARE key)
  - `src/app/`: `glassware_catalog.ts` (spec per `VesselType`: capacity, glass mass, inner radius, tolerance, category), `flow.ts` (batched `ReagentFlowSink`/`VesselFlowSink`/`DrainSink`: ≤10 Hz, one engine request in flight), `instrument_log.ts` (pure per-instrument ring buffers: 10 min sim time, ≤4 Hz, sampled from `sim.onTick`, so paused = no samples), `reaction_clock.ts` (per-vessel timer: starts at first real reaction or manual Start), `setups.ts` + `titration_kit.ts`/`gas_kit.ts`/`filter_kit.ts` (one-click kits), `lab.ts` (vessels, per-vessel controls, hot-plate occupancy, dose/pour actions, `openFlow`/`openDrain`/`transferChunk`, gas links, filters, reaction clock; `ingest()` returns the engine snapshot merged with visual-only contents), `visual_contents.ts` (visual-only liquids/powders for PubChem imports + dissolving ghost piles for engine-dissolved solids), `reagent_library.ts` (catalog + PubChem imports + recently used, search), `reagent_colors.ts` (engine-derived bottle colours), `storage.ts`
  - `src/ui/`: `reagent_panel.ts` (Reagents | Glassware tabs; search-first, PubChem inline), `glassware_panel.ts` (search, categories, Setups, on-bench list), `level_tags.ts` (floating volume/burette/gas readings), `instrument_panel.ts` (right-panel mode for a clicked instrument: live readout, controls, history chart + events), `series_chart.ts` (canvas line chart), `titration_hud.ts`, `gas_section.ts`, `add_card.ts` (guidance + collapsed 'Assisted add'), `vessel_panel.ts` (readouts, events, controls, contents, pour), `time_controls.ts`, `top_bar.ts`, `advanced_view.ts` (Details drawer), `custom_reaction_modal.ts`, `bottle_card.ts`, `self_test.ts`, `toast.ts`, `modal.ts`, `icons.ts`
  - `src/main.ts`: thin composition root (startup, 20 Hz snapshot loop with per-vessel dt, keyboard shortcuts)
- `engine/`: WASM chemistry & solver engine (Rust, wasm-bindgen). Key modules: `vessel.rs` (vessel state/step/snapshot), `vessel_eq.rs` (exact per-equilibrium bisection solver with solids coupled at IAP=Ksp), `vessel_ext.rs` (generic reaction log events, precipitate appearance from mineral registry, settling), `ions.rs` (periodic table, ion tables, `decompose_ionic()` formula→cations/anions), `solubility.rs` + `data/solubility.json` (128 Ksp/solubility rows + acid/base equilibria, generated by `pipeline/build_solubility_table.py`; unknown ion pairs fall back to solubility rules via `auto_minerals()`), `compound_model.rs` (wasm `import_compound`: builds a reacting reagent from a PubChem import's formula/SMILES/state/density)
- `server/`: Local mode server (Python FastAPI, tblite GFN2-xTB, SQLite flywheel)
- `pipeline/`: Data bundle builder (PHREEQC, IUPAC pKa, Joback additivity, curated colors, 500+ species)
- `tests/`: Automated test suite for M0–M2 gates

## Quickstart
``# Launch server and app
python3 run.py

# Run M7 data flywheel (batch precomputations for ML model, e.g. 50 reactions with 4 parallel workers)
python3 run.py --flywheel --flywheel-count 50 --flywheel-workers 4

# Check flywheel stats
python3 run.py --flywheel-stats

# Export ML training dataset
python3 run.py --export-ml ml_dataset.json

# Run tests
pytest tests/ -v

# Run engine tests
cd engine && cargo test

# Build WASM engine
cd engine && wasm-bindgen target/wasm32-unknown-unknown/release/reaction_chamber_engine.wasm --out-dir ../web/src/wasm/engine --target web

# Build bundle
python3 pipeline/build_bundle.py

# Build frontend
cd web && npm run build
```
