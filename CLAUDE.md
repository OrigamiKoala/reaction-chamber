## Design invariants
- **Intrinsic data in, models for the environment.** The simulation relies as much as possible on *intrinsic* values for each
  compound (properties that do not depend on conditions): standard enthalpy and entropy of formation, heat-capacity
  parametrisation, molar mass, molecular structure, acid dissociation constants at a reference state, standard
  potentials, solvation / activity parameters. Quantities that depend on external factors (melting and boiling point,
  vapour pressure, solubility, density at a temperature, pH, state of matter) are *derived* with equations and models
  (Gibbs energy and K(T), Clausius-Clapeyron / Clapeyron, Raoult / Henry / activity models, Antoine, van't Hoff, ...) from
  the vessel's temperature, pressure, composition and solvent. Never store a condition-dependent value as if it were a
  property of the compound; if a database only offers one (e.g. a normal boiling point), store it as a labelled *point on
  a curve* (e.g. (T, 101325 Pa) for the vapour-pressure fit) and derive everything else from it. Phase is never stamped at
  import. When a derived value must be estimated, label its provenance tier (Tabulated / Imported / Estimated /
  Speculative) and prefer sources in order: measured intrinsic data -> group-additivity / semi-empirical estimates.
- Products are compounds exactly like reagents (same import path, same data), because a product can be the next reactant.
- **Master plan for generalisation: `docs/plans/generalization-master-plan.md`** (audit of how every reaction outcome is determined, model choices, the minimal large-database stack, staged implementation with numeric gates). Evidence and probe scripts: `docs/plans/generalization-audit/`. Older background: `COMPOUND_PHASE_PLAN.md`, `docs/plans/generality-audit.md` (F1–F47), `docs/plans/data-sources.md`.

## Quickstart
``# Launch server and app
python3 run.py

# Run M7 data flywheel (batch precomputations for ML model, e.g. 50 reactions with 4 parallel workers)
python3 run.py --flywheel --flywheel-count 50 --flywheel-workers 4

# Check flywheel stats
python3 run.py --flywheel-stats

# Export ML training dataset
python3 run.py --export-ml ml_dataset.json

# Run tests
pytest tests/ -v

# Run engine tests
cd engine && cargo test

# Build WASM engine
cd engine && wasm-bindgen target/wasm32-unknown-unknown/release/reaction_chamber_engine.wasm --out-dir ../web/src/wasm/engine --target web

# Build bundle
python3 pipeline/build_bundle.py

# Build frontend
cd web && npm run build
```

- **Structure-based NMR and mass spectrometry (2026-10-03)**: the NMR console and the GC/MS no longer look anything up. Both read the SMILES graph of every species in the vessel's liquid (imports carry it from PubChem; the species store holds it for built-in ones), so any compound that has a structure can be measured. Engine side (`engine/src/analytical/`, `vessel_analytical.rs`, wasm `vessel_nmr_spectrum(handle, layer, nucleus, solvent, scans, seed)` and `vessel_ms_spectrum(handle, layer, mode, seed)`, worker messages `NMR_SPECTRUM` / `MS_SPECTRUM`, `SimController.nmrSpectrum` / `msSpectrum`):
  - `graph.rs` (heavy-atom graph with H counts from SMILES, aromaticity perception, rings, Morgan symmetry classes, Hill formula), `isotopes.rs` (exact isotope masses / abundances for 50 elements, isotopic distributions by convolution).
  - NMR (`nmr_shift.rs`, `spin.rs`, `nmr.rs`): 1H shifts by Curphy-Morrison alkyl increments, Pretsch alkene and benzene increments, pyridine- and five-ring heteroaromatic bases, solvent-dependent shifts of exchangeable protons; 13C by Grant-Paul / Lindeman-Adams alkane increments with branching and ring corrections, substituent alpha/beta/gamma tables, Pretsch alkene and benzene SCS, class values for carbonyl / nitrile / alkyne carbons, C-F coupling. J couplings from connectivity (vicinal sp3 with ring and polar corrections, alkene cis / trans from ring size and =CH2 slot, aromatic ortho / meta / para and heteroaromatic values, allylic, propargylic, H-X-C-H in slow-exchange solvents). Spin systems from the coupling graph: first-order n+1 multiplets, and an exact Hamiltonian simulation (`spin::simulate_exact`, Jacobi diagonalisation per M block, <= 9 spins) when shift difference < 15 J, so AA'BB' and roofing appear. Sample prep: 150 uL liquid + 450 uL deuterated solvent (dry vessel: 30 mg of solid in 0.6 mL); concentrations set relative intensities; residual solvent multiplets (CDCl3 CHCl3, DMSO-d5 quintet, ...), TMS/DSS, water in the solvent's position; protic solvents exchange all O-H / N-H into the HDO line; in CDCl3-type solvents alcohol / acid / water protons coalesce into one averaged line; signal-to-noise per scan (1H 15 per mM per H per scan, 13C 1.76e-4 x NOE) with sqrt(scans) averaging hides weak signals (13C of a 25 mM tube needs thousands of scans); an aqueous layer in CDCl3 / C6D6 is flagged biphasic. Output: signals (ppm, multiplicity, J, integral, nuclei, assignment, species, S/N, extent), a 32768 (1H) / 65536 (13C) point digitised spectrum with noise, species that could not be simulated, notes, tier.
  - Mass spec (`ms_thermo.rs`, `ms_ei.rs`, `gc.rs`, `ms.rs`): EI by a quasi-equilibrium (RRKM-style) model. M+. has an internal-energy distribution (gamma components plus a high-energy tail); every ion has channels with thresholds from group-additive energetics (IE of molecules and radicals by functional class, bond dissociation energies with radical stabilisation, AE = D + IE(R.) - IE(M)): all single-bond cleavages both ways, H loss, McLafferty (carbonyl / alkene / aromatic acceptors), water and HX loss, alkene loss from ethers, aryl methyl ether CH2O loss, retro-Diels-Alder, ring contraction by C2H4 loss, C2H2 / CO / HCN losses from aromatics, nitro-nitrite NO loss, and decays of even-electron ions (acylium CO loss, oxonium alkene loss, hydrocarbon cations by formula, benzyl / phenyl cations); rates k = A ((E - E0)/E)^(s-1) compete at each energy, daughters inherit the leftover energy; survivors are the peaks; isotope patterns from the exact table. The 8 model constants (`EiParams`) were fitted to 29 reference spectra, and checked on 15 compounds that were not fitted. GC: retention from the vapour-pressure model (dHvap/R from the species' saturation curve, T1 = 0.92 Tb) integrated through a 40 -> 300 C programme (`gc.rs`); species that are ionic, have no structure, or boil above the programme are reported as not analysed; peak areas = amount x additive EI cross-section. ESI: [M+H]+ (response by basic-site class, amines >> amides >> ethers, alkanes none), [M+Na]+ / [M+K]+ for O/N donors, [M+H-H2O]+ for alcohols, proton-bound dimers at high concentration, [M-H]- by acidic-site class in negative mode, pre-formed ions (Na+, Cl-, ...) pass straight through, droplet ion suppression, isotope patterns at m/z = mass / z.
