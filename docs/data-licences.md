# Data licence ledger

One line per source that was fetched for `docs/plans/data-acquisition-plan.md`. **Status: not reviewed.** Decision of
2026-10-06: the data were integrated first (academic, non-commercial use) and the licences are to be dealt with later.
Everything marked *flag* must be reviewed before the repository (or the GitHub Pages build, which embeds the data in the WASM) is
published or redistributed. What is committed from each source is listed so that it can be removed or replaced.
